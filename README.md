# Shogi King（試作版）

将棋 × カードゲーム（遊戯王風）の対戦ゲーム。

## 遊び方
- PC：`index.html` をダブルクリックしてブラウザで開く
- iPhone：公開したページを Safari で開き、「共有 → ホーム画面に追加」するとアプリのように使えます

## ルール
- 盤面：5×5。いちばん手前の行が自分の**陣**（援軍を置ける行）
- お互いの王は自分の陣の真ん中から始まる
- 陣にもほかのマスと同じように入れる。相手の駒が自分の陣にいると、そのマスには援軍を出せない
- デッキ20枚ちょうど（駒カード＋指令カード）。同じカードは2枚まで（飛車・角行は1枚、歩兵は上限なし）。全カードを最初から使える
- タイトルの「Myデッキ」でデッキを1つ作って保存できる。CPUは標準デッキを使う
- 初期手札4枚
- マナ：先攻は1、後攻は2から始まり、毎ターン+1（最大3）。余ったマナは持ち越さない
- 手番の流れ
  1. カードを1枚引く
  2. 手札の駒を自分の陣の空いているマスに置く＝**援軍**（マナの範囲で何枚でも）
  3. 駒を**必ず1つ**動かす（援軍で出した駒もすぐ動かせる）。動かすと**自動でターン終了**（ターン終了ボタンはない）
- 指令カードはマナが足りる限り何枚でも使える
- 援軍・指令は駒を動かす前だけ（進軍で2回動かせるときも、1回目を動かしたあとは使えない）
- 動かせる駒が1つもないときだけ「パス」でターンを終えられる（援軍を出せば動かせるようになる場合もある）
- 持ち時間：1ターン30秒は自由に使える。過ぎた分は各自の持ち時間（全体で5分）から減り、0になったら負け（CPU戦・2人対戦・オンラインすべて。2人対戦では交代画面を閉じたときから数える）
- 動いた先にいる相手の駒を倒せる。倒した駒は倒した側の手札に加わる
- 成りはなし。山札が切れても負けにはならず、引けなくなるだけ
- 相手の王を取ったら勝ち

## 仮で決めたこと（要調整）
- 1ターン目から両者ともカードを1枚引く
- 2人対戦では両者ともMyデッキを使う（Myデッキが未作成なら標準デッキ）
- 突風：コストは1マナ。「左」は使った人から見た左。左のマスが空いている駒だけ選べる。王も選べる。動かした駒は、そのターンが終わるまで移動できない（相手の駒は相手の次のターンには動ける）
- 防人：防人自身と、周囲8マスにいる防人と同じ持ち主の駒が守られる（盤上では青い点線で表示）
- 砲兵：「前方3マス」は砲兵の前の行の左前・前・右前。撃ち出せるのは自分の歩兵。歩兵は間の駒を飛び越えて2マス先へ進む。行き先が自分の駒・盤の外なら撃てない。相手の王も撃ち取れる。消えた歩兵は誰の手札にも入らない
- 伏兵：「陣以外」は自分と相手の両方の陣を除いた真ん中の行。効果は次の1回の援軍だけで、そのターンが終わると消える。効果中は陣には援軍を出せない。伏兵で出した駒はそのターン移動できない（砲兵なら撃ち出しもできない）。駒を動かした後や、すでに効果中のときは使えない
- 縛兵：「次のターン」は、取った駒の持ち主の次の手番。落雷で破壊したときや、砲兵の撃ち出し（歩兵はどのみち消える）では効果なし。動けない駒は薄く表示
- 香車・角行・飛車・龍のまっすぐの動きは2マス先まで。途中に駒があればそこで止まる（飛び越えない）
- 龍：倒されたとき・撤退で手札に戻るときは飛車に戻る。龍化は何度でも使えるが、龍になった駒は対象外

## ファイル構成
```
Shogi-King/
├─ index.html     画面の骨組み（これを開くと起動）
├─ bgm/
│  └─ bgm1.mp3    対局中のBGM
├─ 効果音/
│  └─ 将棋・駒を指す03.mp3   駒を動かしたときの音
├─ css/
│  └─ style.css   見た目（色・大きさ・配置）
├─ js/
│  ├─ config.js   カードと数値の設定 ← バランス調整はここ
│  ├─ engine.js   ルールエンジン（画面・音に触れない。ブラウザでもサーバーでも使う）
│  ├─ cpu.js      CPUの思考（盤面を見て「次の操作」を返す。サーバーでも使える）
│  ├─ storage.js  データの保存（今は localStorage）
│  ├─ sound.js    BGMと効果音（使うファイル名と音量もここ）
│  ├─ match.js    対局の進行（操作をエンジンに渡し、結果でログ・音・画面を更新）
│  ├─ ui.js       対局画面の描画とタップ操作、メニュー
│  ├─ deck.js     Myデッキ（デッキビルド画面）
│  └─ online.js   オンライン対戦（サーバーとの通信、ルーム作成・参加、再接続、残り時間）
├─ server/        オンライン対戦サーバー（Cloudflare Workers + Durable Objects）
│  ├─ src/index.js  ルーム・審判・持ち時間・切断の判定
│  ├─ wrangler.jsonc  Cloudflare の設定
│  └─ package.json
└─ tests/
   ├─ selfplay.js     エンジンの動作確認（node tests/selfplay.js）
   └─ server-test.mjs 対戦サーバーの動作確認
```
JavaScript は config → engine → cpu → storage → sound → match → online → ui → deck の順に読み込まれます。

## エンジンの仕組み
- 対局の状態（state）はただのデータで、そのまま JSON にして通信で送れる
- 操作もデータで表す
  - 援軍：`{ type:'summon', p:0, cardId:12, r:4, c:0 }`
  - 指令：`{ type:'command', p:0, cardId:15, picks:[{r:2,c:2},{r:3,c:1}] }`
  - 移動：`{ type:'move', p:0, from:{r:3,c:1}, to:{r:2,c:1} }`
  - 砲兵の撃ち出し：`{ type:'launch', p:0, from:{r:3,c:3}, to:{r:0,c:4} }`
  - ターン終了：`{ type:'endTurn', p:0 }`／降参：`{ type:'resign', p:0 }`
- `Engine.apply(state, 操作)` がルールを確認して state を更新し、起きたこと（events）を返す。ルール違反なら理由を返して何も変えない
- ログの文章や効果音は、画面側（match.js）が events を見て出す
- 山札のシャッフルはシード付きの乱数。同じシードなら同じ対局になる
- `Engine.viewFor(state, p)` で、プレイヤー p に見せてよい情報だけにしたコピーを作れる（相手の手札・山札の中身・乱数の種を隠す）

## オンライン対戦の方針（決定事項）
- 対戦相手はルームコードで探す
- ログインはなし。名前だけ入れて遊ぶ（裏で端末ごとのIDを使い、再接続に使う）
- サーバーが審判をする方式。山札・手札・盤面はサーバーが持ち、各プレイヤーには viewFor で見せてよい情報だけ送る
- 持ち時間：1ターン30秒＋各自の持ち時間5分（config.js の TURN_SEC・BANK_SEC）。0になったら負け
- 切断：60秒以内に戻れば続きから。戻らなければ負け
- Myデッキはスマホの中に保存したまま、対戦開始時にサーバーへ送ってサーバーで確認する（DBはまだ使わない）

## 音について
- 対局が始まるとBGMが流れ、対局が終わるかタイトルに戻ると止まる
- 駒を動かすと（CPUの手も含めて）駒を指す音が鳴る
- メニューの「BGM・効果音」でON/OFFを切り替えられる（設定は保存される）
- スマホはタップしたときしか音を鳴らし始められないため、最初のタップで音の準備をしている

## オンライン対戦サーバーの公開手順（Cloudflare）
初回だけ、PC（Windows）で次を行う。
1. Node.js（LTS版）を https://nodejs.org からインストールする
2. コマンドプロンプトで
   ```
   cd C:\Users\keisy\Documents\iphone_app\Shogi-King\server
   npm install
   npx wrangler login
   npx wrangler deploy
   ```
   - `wrangler login` でブラウザが開くので、Cloudflare にログインして「Allow」を押す
   - `wrangler deploy` が終わると `https://shogi-king-server.〇〇.workers.dev` というURLが表示される
3. 表示されたURLを `js/online.js` の `SERVER` に入れて push する（設定済み：https://shogi-king-server.sawa-d.workers.dev）
4. ブラウザで `https://shogi-king-server.〇〇.workers.dev/health` を開き、`{"ok":true,...}` と出れば動いている

サーバーのプログラムを変えたときは、server フォルダで `npx wrangler deploy` をもう一度実行する。

### PCだけで試す（公開しなくても動かせる）
- server フォルダで `npx wrangler dev` を実行する
- ブラウザを2つ（片方はシークレットウィンドウ）開き、`index.html?server=http://127.0.0.1:8787` を開いて対戦する

## データの保存について
Myデッキはブラウザの localStorage に保存されます（端末・ブラウザごと）。
オンライン対戦を作る段階で、`js/storage.js` の中身をDB（Firebase / Supabase など）に置き換える予定です。
保存形式：`{ "version":1, "name":"Myデッキ", "cards":{ "fu":6, "kin":2, ... }, "updatedAt":"..." }`

## 数値の調整方法
`js/config.js` の `CONFIG`（盤の広さ、初期手札、マナ、デッキ構成）と `CARDS`（各カードのコスト・動き・説明）を書き換えます。
