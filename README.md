# Shogi King（試作版）

将棋 × カードゲーム（遊戯王風）の対戦ゲーム。

## 遊び方
- PC：`index.html` をダブルクリックしてブラウザで開く
- iPhone：公開したページを Safari で開き、「共有 → ホーム画面に追加」するとアプリのように使えます

## ルール
- 盤面：戦場7×7＋両端に「陣」が1行ずつ（7×9）
- お互いの王は、戦場の自陣側の真ん中から始まる
- デッキ30枚ちょうど（駒カード＋指令カード）。同じカードは2枚まで（飛車・角行は1枚、歩兵は上限なし）。全カードを最初から使える
- タイトルの「Myデッキ」でデッキを1つ作って保存できる。CPUは標準デッキを使う
- 初期手札5枚
- マナ：先攻は1、後攻は2から始まり、毎ターン+1（最大3）。余ったマナは持ち越さない
- 手番の流れ
  1. カードを1枚引く
  2. 手札の駒を自分の陣に置く＝**援軍**（マナの範囲で何枚でも）
  3. 駒を1つ動かす。陣から戦場へは1マス前にだけ進める＝**出陣**
- 指令カードはマナが足りる限り何枚でも使える
- 戦場から陣には入れない（自分の陣にも相手の陣にも）
- 動いた先にいる相手の駒を倒せる。倒した駒は倒した側の手札に加わる
- 成りはなし。山札が切れても負けにはならず、引けなくなるだけ
- 相手の王を取ったら勝ち

## 仮で決めたこと（要調整）
- 召喚した駒はそのターン中に動かせる。駒を動かしたあとは援軍を出せない
- 駒を動かすかどうかは自由（動かさずにターン終了してもよい）
- 1ターン目から両者ともカードを1枚引く
- 2人対戦では両者ともMyデッキを使う（Myデッキが未作成なら標準デッキ）

| カード | 種類 | マナ | 効果 | 標準デッキの枚数 |
|---|---|---|---|---|
| 歩兵 | 駒 | 1 | 前に1マス | 16 |
| 香車 | 駒 | 2 | 前にどこまでも | 2 |
| 金将 | 駒 | 2 | 斜め後ろ以外に1マス | 2 |
| 角行 | 駒 | 3 | 斜めにどこまでも | 1 |
| 飛車 | 駒 | 3 | 縦横にどこまでも | 1 |
| 進軍 | 指令 | 1 | このターン、駒をもう1回動かせる | 2 |
| 補給 | 指令 | 1 | カードを2枚引く | 2 |
| 撤退 | 指令 | 1 | 自分の駒1つ（王以外）を手札に戻す | 2 |
| 落雷 | 指令 | 3 | 相手の駒1つ（王以外）を破壊 | 2 |

## ファイル構成
```
Shogi-King/
├─ index.html     画面の骨組み（これを開くと起動）
├─ css/
│  └─ style.css   見た目（色・大きさ・配置）
└─ js/
   ├─ config.js   カードと数値の設定 ← バランス調整はここ
   ├─ storage.js  データの保存（今は localStorage。オンライン化でDBに置き換える）
   ├─ game.js     ゲームの状態とルール（移動・援軍・指令・勝敗・デッキのチェック）
   ├─ cpu.js      CPUの思考
   ├─ ui.js       対戦画面の描画とタップ操作、メニュー
   └─ deck.js     Myデッキ（デッキビルド画面）
```
JavaScript は config → storage → game → cpu → ui → deck の順に読み込まれます。

## データの保存について
Myデッキはブラウザの localStorage に保存されます（端末・ブラウザごと）。
オンライン対戦を作る段階で、`js/storage.js` の中身をDB（Firebase / Supabase など）に置き換える予定です。
保存形式：`{ "version":1, "name":"Myデッキ", "cards":{ "fu":16, "kin":2, ... }, "updatedAt":"..." }`

## 数値の調整方法
`js/config.js` の `CONFIG`（盤の広さ、初期手札、マナ、デッキ構成）と `CARDS`（各カードのコスト・動き・説明）を書き換えます。
